# The reading list behind the Books page.
#
# One book per block, with a line of three dashes between books:
#
#     title: Chaos: Making a New Science
#     author: James Gleick
#     read: 2024-03-10
#     favourite: yes
#     cover: chaos.jpg
#
#     Anything written after a blank line is the review. It can run to
#     several paragraphs, and may use Markdown and [[wiki links]].
#
#     ---
#
# Only the title is required. The fields:
#
#     title      the book's title, written as you like (colons are fine)
#     author     who wrote it; books are shelved by the author's surname
#     read       when you finished it: 2024-03-10, 2024-03 or just 2024
#     status     read, reading or to read (left out, the book counts as read)
#     favourite  yes puts it on the Favourites shelf
#     cover      the name of an image in src/assets/covers/
#                (left out, the cover is set in type)
#     link       a web address for the book; left out, the card links to a
#                search for it on Open Library
#     note       the name of an entry in src/notes/ about the book,
#                e.g. plate-i
#
# Add books below this line, without the leading "#".
